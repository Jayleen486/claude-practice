# Portfolio Website

A simple, modern, single-page personal portfolio site built with plain HTML, CSS, and JavaScript (no build tools required).

## Structure

```
├── index.html          Main page (Home, About, Projects, Skills, Contact)
├── css/
│   └── style.css       Styles
├── js/
│   └── main.js         Mobile nav toggle + footer year
├── assets/
│   └── images/         Put your photos and project screenshots here
└── README.md
```

## Running locally

Just open `index.html` in your browser, or serve it locally:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000

## Next steps

- Replace the `[bracketed placeholders]` in `index.html` with your real name, title, bio, projects, skills, and contact links.
- Add a profile photo and project screenshots to `assets/images/` and reference them in `index.html`.
- Deploy for free on GitHub Pages, Netlify, or Vercel once content is filled in.
